HTML Lists

HTML lists group related items and give them meaningful structure. Choose a list type based on the relationship between its items.

Unordered · Ordered · Description · Nested · Guidelines

1. Unordered lists: <ul>

Use an unordered list when the order is not important, such as a collection of ingredients. Each item must be an <li> (list item).

<ul>
	<li>Flour</li>
	<li>Water</li>
	<li>Yeast</li>
</ul>

Rendered example:

  • Flour
  • Water
  • Yeast

Browsers normally display bullets. Change their appearance with CSS, for example ul { list-style-type: square; }, rather than using obsolete list attributes.

2. Ordered lists: <ol>

Use an ordered list when sequence or ranking matters, such as steps in a procedure.

<ol>
	<li>Gather the ingredients.</li>
	<li>Mix them together.</li>
	<li>Bake until ready.</li>
</ol>

Rendered example:

  1. Gather the ingredients.
  2. Mix them together.
  3. Bake until ready.

Ordered-list options

  • start="4" begins numbering at 4.
  • reversed counts down instead of up.
  • type="A", type="a", type="I", or type="i" uses letters or Roman numerals. The default is decimal numbers.
<ol start="3" type="A">
	<li>This item is C.</li>
	<li>This item is D.</li>
</ol>

Rendered example:

  1. This item is C.
  2. This item is D.

The value attribute on an <li> can set an item's number in an ordered list; later items continue from that value.

<ol>
	<li>First</li>
	<li value="10">Number ten</li>
	<li>Number eleven</li>
</ol>

3. Description lists: <dl>, <dt>, and <dd>

A description list represents terms and their descriptions, or similar name-value groups. The <dl> contains terms (<dt>) and descriptions (<dd>).

<dl>
	<dt>HTML</dt>
	<dd>Structures content on the web.</dd>
	<dt>CSS</dt>
	<dd>Styles web pages.</dd>
</dl>

Rendered example:

HTML
Structures content on the web.
CSS
Styles web pages.

A term may have more than one description. Keep the relationships between terms and descriptions clear.

4. Nested lists

A list can be placed inside an <li> to represent sub-items. The nested list belongs inside its parent list item.

<ul>
	<li>Fruit
		<ul>
			<li>Apples</li>
			<li>Oranges</li>
		</ul>
	</li>
	<li>Vegetables</li>
</ul>

Rendered example:

  • Fruit
    • Apples
    • Oranges
  • Vegetables

Ordered and unordered lists may be nested inside either kind. Avoid unnecessary nesting so the hierarchy stays easy to follow.

5. Good practices and common mistakes

  • Use <ul> when order does not matter, <ol> when it does, and <dl> for term-description relationships.
  • Place list items in <li> elements; do not use list markup solely to create indentation or visual bullets.
  • Use CSS for visual styling and preserve markers when they help communicate the list structure.
  • Semantic lists help browsers and assistive technologies identify related items and their hierarchy.

Quick rule: If changing the order changes the meaning, use an ordered list. Otherwise, use an unordered list.

The core HTML list elements are <ul>, <ol>, <li>, <dl>, <dt>, and <dd>.
