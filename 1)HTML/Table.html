HTML Tables: A Complete Guide

Use an HTML table to present data that naturally belongs in rows and columns, such as schedules, comparisons, or reports. Do not use tables to lay out an entire page.

1. A basic table

The <table> element contains the table. Each <tr> is a row, <th> marks a heading cell, and <td> holds ordinary data.

<caption> gives the table a title. Group header rows in <thead> and data rows in <tbody>; an optional <tfoot> is useful for totals or summaries.

2. Header cells and accessibility

Use <th> for cells that label a row or column, and <td> for data. The scope attribute connects a heading to its column (scope="col") or row (scope="row"), helping assistive technology explain the table context.

Give each table a useful caption, keep the structure simple, and do not use spaces or empty cells to create visual layout. For complicated multi-level headings, use explicit header associations such as id and headers.

3. Combining cells with colspan and rowspan

colspan makes a cell span multiple columns; rowspan makes it span multiple rows. Other cells must be arranged so every row still fits the intended grid.

5. The same table in HTML

This short example shows the nesting pattern. The browser creates rows and columns from the markup; CSS controls the visual presentation.

<table>
	<caption>Books in the library</caption>
	<thead>
		<tr>
			<th scope="col">Title</th>
			<th scope="col">Author</th>
		</tr>
	</thead>
	<tbody>
		<tr>
			<td>Example Book</td>
			<td>A. Writer</td>
		</tr>
	</tbody>
</table>

6. Styling and good practices

  • Use CSS for borders, spacing, colors, and alignment; avoid obsolete presentational attributes such as border on the table.
  • border-collapse: collapse combines adjacent borders. padding makes cell contents easier to read.
  • Keep tables readable on small screens. This page puts wide tables in a wrapper with overflow-x: auto.
  • Use tables for tabular data, not for page layout. Use CSS Grid or Flexbox for layout.

A table is most useful when the relationship between each row and column matters. Choose clear headings and meaningful data before adding decoration.
