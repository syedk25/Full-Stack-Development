# Before you start

This is a standalone hands-on IDE course for Java developers who want a practical
introduction to Spring Boot and Spring AI foundations.

You should already be comfortable with basic Java:

- classes and methods
- method parameters and return values
- imports
- simple strings and lists

You do not need previous Spring Boot or AI experience. The course starts with
basic REST endpoints, then builds toward ChatClient-style calls, prompts,
templates, and structured output.

All AI-related checks use deterministic fake models. You can complete the course
without an API key, AI provider account, or external course material.
