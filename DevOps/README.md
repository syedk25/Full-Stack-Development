DevOps is a combination of cultural philosophies, practices, and 

tools that unites software development (Dev) and
      IT operations (Ops) teams to deliver applications and services faster and more reliably


Common DevOps Tools

• Planning & Collaboration: Jira, Confluence, Azure Boards
• Version Control: Git, GitHub, GitLab
• CI/CD & Builds: Jenkins, GitLab CI/CD, Maven
• Infrastructure & Deployment: Kubernetes, Docker, Ansible, Terraform
• Monitoring & Observability: Prometheus, Grafana, Datadog
